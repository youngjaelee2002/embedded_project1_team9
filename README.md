# 자동 감시 · 표적 조준 시스템

임베디드 시스템설계 Project 1 · 9조

회전하는 ToF 거리 센서로 600 × 600mm 감시 영역의 물체를 찾고, 위험한 표적을 골라 두 포탑이 레이저로 교차 조준한 뒤 모의 사격을 하는 시스템입니다. Arduino Uno 4개가 감지, 판단, 표시, 조준을 나누어 맡고, 중앙 제어기(1번)가 UART · SPI · I2C로 나머지 보드를 연결합니다.

시연 영상: https://youtu.be/OpTgW8evwVk

## 보드 구성

| 보드 | 역할 | 주요 부품 | 통신 |
|---|---|---|---|
| Arduino 1 | 중앙 제어: 표적 검증·선택, 위험 판단, 사격 승인 | Arduino Uno | UART · SPI 슬레이브 · I2C 마스터 |
| Arduino 2 | UI: 표적 표시, 경보, 모드·사격·스캐너 명령 입력 | 16×2 I2C LCD, RGB LED, 부저, 버튼 3개 | UART (9600bps) |
| Arduino 3 | 스캐너: 센서 회전, 거리 측정, 표적 ID·위치·속도 계산 | VL53L0X, 17HS4023 + TB6600, 홀 센서 | SPI 마스터 (125kHz, 48바이트/100ms) |
| Arduino 4 | 포탑: 두 포탑 교차 조준, 레이저 모의 사격 | SG90 서보 ×2, KY-008 레이저 ×2 | I2C 슬레이브 (0x20) |

## 통신 설계

- **UART (1번 ↔ 2번):** 사용자 입력은 언제 생길지 모르므로, 마스터 없이 2번이 바로 보낼 수 있는 UART를 사용했습니다.
- **SPI (3번 → 1번):** 48바이트 탐지 데이터를 보내는 같은 전송 안에서 1번의 스캐너 명령을 동시에 받을 수 있는 전이중 SPI를 사용했습니다. CRC-8로 오류를 검사합니다.
- **I2C (1번 → 4번):** 1번이 명령을 보내고 20ms마다 조준 상태를 읽는 구조라, 마스터-슬레이브 방식과 ACK가 있는 I2C를 사용했습니다.
- 세 연결을 ATmega328P의 UART, SPI, TWI 하드웨어에 하나씩 배정해서, 1번이 세 보드와 동시에 통신합니다.

## 동작 흐름

1. **감지:** 3번이 센서를 회전시켜 표적을 찾고 SPI로 1번에 보냅니다.
2. **판단:** 1번이 좌표를 검증하고 표적을 고른 뒤, 2번 LCD에 표시합니다.
3. **조준:** 4번의 두 포탑이 같은 좌표를 교차 조준합니다.
4. **확인:** 1번이 4번 상태를 읽어 조준 완료를 확인합니다.
5. **사격:** AUTO는 위험 표적이면 자동으로, MANUAL은 FIRE 버튼을 누르면 사격합니다. 레이저가 5초 동안 깜박입니다.
